= kafka-zen-lab-802-saga-choreographed

A multi-module Gradle project demonstrating the **Saga Choreography** pattern across four independent
Spring Boot microservices connected through Apache Kafka, built on Hexagonal (Ports and Adapters) Architecture.

There is no central orchestrator. Each service reacts to domain events published by other services and
publishes its own events in response. The `order-service` starts the saga by publishing an `ORDER_PLACED`
event and later reacts to terminal events to confirm or cancel the order. A **Transactional Outbox** with
**Debezium CDC** ensures events are published atomically with their database changes.

== Technology

Java 21 · Spring Boot 4.x · Apache Kafka · Debezium CDC · PostgreSQL · Flyway · ArchUnit · Testcontainers · Jib

== Quick Start

[source,bash]
----
# Build all modules
./gradlew build

# Start infrastructure (PostgreSQL + Kafka + Debezium Connect)
docker compose -f docker/docker-compose.yml up -d postgres zookeeper kafka connect connector-registrar

# Run services (separate terminals)
./gradlew :order-service:bootRun
./gradlew :inventory-service:bootRun
./gradlew :payment-service:bootRun
./gradlew :shipping-service:bootRun
----

Swagger UI: http://localhost:8080/swagger-ui/index.html
